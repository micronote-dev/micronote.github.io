# Issues

Micronote includes a lightweight issue tracker stored as a local Markdown file (`Issue.mtf.md`) inside each project.

## Creating an issue

Open a project, switch to the Issues view, and press `+ New issue`. Each issue has a title and a status.

## Statuses

| Status | Description |
|--------|-------------|
| Backlog | Not yet started |
| In Progress | Currently being worked on |
| Done | Completed |

## Views

Issues can be viewed in three layouts:

- **Kanban** — drag-and-drop board grouped by status
- **Backlog** — flat list sorted by creation date
- **Text** — raw Markdown view of the underlying file

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| `n` | New issue |
| `Enter` | Open selected issue |
| `Tab` | Cycle through views |
