# Getting Started

Micronote is a local-first, Vim-native note-taking app for macOS. This guide gets you from zero to writing in under a minute.

## Download

Download the latest release from the [download page](/download) or directly from [GitHub Releases](https://github.com/micronote-dev/micronote/releases).

## Install

1. Open the downloaded `.dmg` file.
2. Drag `Micronote.app` to your Applications folder.
3. Launch Micronote from Applications or Spotlight.

If macOS shows a Gatekeeper warning on first launch, right-click the app and choose **Open**.

## Open a workspace

Micronote works with local directories. On first launch, it will ask you to open a folder. This folder becomes your workspace — all notes and project files live there as plain Markdown files.

```
~/my-notes/
├── ideas.md
└── projects/
    └── micronote.md
```
