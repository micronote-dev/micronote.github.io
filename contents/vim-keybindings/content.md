# Vim Keybindings

Micronote uses Vim-style navigation throughout the app, not just in the editor.

## Editor modes

| Key | Action |
|-----|--------|
| `Esc` | Normal mode |
| `i` | Insert mode |
| `v` | Visual mode |

## Normal mode

| Key | Action |
|-----|--------|
| `h` `j` `k` `l` | Move left / down / up / right |
| `w` `b` | Next / previous word |
| `0` `$` | Start / end of line |
| `gg` `G` | Top / bottom of file |
| `dd` | Delete line |
| `yy` | Yank (copy) line |
| `p` | Paste |
| `u` | Undo |
| `Ctrl-r` | Redo |

## Navigation

| Key | Action |
|-----|--------|
| `/` | Search |
| `:` | Command palette |
| `Tab` | Next file in sidebar |
| `Shift-Tab` | Previous file in sidebar |
