# Notes

Notes in Micronote are plain Markdown files stored in your workspace directory.

## Creating a note

Press `+` in the sidebar or use the command palette (`:`) and type `new note`. Micronote will create a new `.md` file in the current project.

## Markdown support

Micronote renders standard Markdown with live preview:

- Headings (`#`, `##`, `###`)
- Lists (ordered and unordered)
- Code blocks with syntax highlighting
- Bold, italic, inline code
- Links

## Organizing notes

Notes are organized by directory. Each directory in your workspace appears as a project in the sidebar. You can nest directories freely.

```
workspace/
├── journal/
│   └── 2026-08-30.md
└── work/
    ├── meetings.md
    └── ideas.md
```

## Search

Press `/` to search across all notes in the current workspace. Search matches on file name and content.
